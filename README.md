# 🌸 Machine Learning Lab – Experiment 1

## 📌 Experiment Title

**Iris Flower Classification using Decision Tree Classifier**

## 🎯 Aim

To implement a Decision Tree classification algorithm using the Iris dataset and predict the species of an iris flower.

## 📝 Description

This experiment demonstrates the basic workflow of a machine learning classification problem using the Iris dataset. The dataset is explored and visualized, divided into training and testing data, and a Decision Tree Classifier is trained to classify iris flowers into their respective species.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* Scikit-learn
* Seaborn
* Matplotlib

## 📊 Dataset

The **Iris dataset** contains measurements of iris flowers based on:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The flowers are classified into:

* Setosa
* Versicolor
* Virginica

## 🔬 Steps Performed

1. Import the required Python libraries.
2. Load the Iris dataset.
3. Check for missing values.
4. Generate descriptive statistics.
5. Visualize the dataset using a pair plot.
6. Separate features (`X`) and target (`y`).
7. Split the dataset into training and testing sets.
8. Train a Decision Tree Classifier.
9. Generate a classification report.
10. Display the confusion matrix.
11. Visualize the trained decision tree.
12. Predict the class of a new iris flower.

## 🌳 Algorithm

**Decision Tree Classifier**

A Decision Tree is a supervised machine learning algorithm used for classification. It makes predictions by learning decision rules from the training data.

## 💻 Sample Prediction

The experiment uses the following flower measurements:

```text
Sepal Length = 4.8
Sepal Width  = 2.9
Petal Length = 1.3
Petal Width  = 0.2
```

The trained model predicts the corresponding Iris species.
